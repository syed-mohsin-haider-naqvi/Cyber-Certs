# HackTheBox (HTB Academy)

HTB Academy is where I did most of my structured defensive/blue-team learning — modules that combine theory with real hands-on labs, generally harder and more technical then LetsDefend or most of the TryHackMe SOC path. Completed the full SOC Analyst path plus additional individual modules covering malware analysis and Windows log forensics specifically.

A fair amount of this material was genuinely new to me going in, so part of working through these modules meant referencing HTB's own documentation, Microsoft's event log references, and general write-ups when I hit something I didn't already know — thats a normal part of how this kind of investigative work actually gets done, not something I'm trying to hide. The actual investigation steps, queries, and reasoning in each writeup are mine; where I leaned on outside reference to understand a concept first, I've tried to note that honestly rather than pretend everything was immediate.

## What's In This Folder

Each folder here is a real hands-on module I worked through, picked specifically because it involved actual investigation and analysis work rather then just theory and quiz questions.
