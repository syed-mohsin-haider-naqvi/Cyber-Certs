# TryHackMe

TryHackMe is where I started with SOC-focused learning, working through their SOC Level 1 path — 14 sections covering everything from blue team basics through SIEM, network/web/Windows/Linux security monitoring, malware concepts, and capstone-level incident investigation rooms.

Originally planned to write up two of the SOC Level 1 capstone rooms specifically (Tempest and The Greenholt Phish), but both turned out to be premium-gated on my account even though I'd completed them before — TryHackMe locks a chunk of the harder/capstone content behind a subscription, which isnt something I can afford right now. Rather then wait on that, picked two different rooms that still show genuinely useful, distinct skills.

---

## What's In This Folder

- **[01-ai-threat-modelling-assessment/](./01-ai-threat-modelling-assessment/)** — an interactive threat modelling assessment focused on AI systems specifically. Picked this one deliberately since AI security is a newer area im building toward alongside cloud and OT/ICS — almost nobody at entry level has this on their radar yet, and structured threat modelling (not just finding one bug) is a genuinely different skill from the investigation-style writeups elsewhere in this repo.

- **[02-missing-person/](./02-missing-person/)** — an OSINT investigation room, tracking down a missing person using nothing but public information gathering techniques. This is the one pure OSINT piece in my whole portfolio right now — connects directly to skills id use later for OT/ICS reconnaissance work (finding exposed info on a company/target using public sources) even though this specific room is framed as a missing-person case.
