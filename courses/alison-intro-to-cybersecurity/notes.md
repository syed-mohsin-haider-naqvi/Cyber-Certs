# Notes — Diploma in Cyber Security (Alison)

Module by module, same format as my other course notes. This one's structured a bit differently then cisco — each module has 2-3 bigger topics inside it rather then a long list of small numbered lessons, so these notes are organized around those topics instead.

---

## Module 1 — Network and System Security

### Introduction to Cybersecurity
Covers the basics again — cybersecurity in the digital age, overview of threats and attack vectors, and legal/ethical considerations specifically. The legal/ethical part was newer ground compared to how cisco covered ethics (cisco had the code of conduct lab in Cyber Threat Management but this went into it from a more formal legal angle too, not just personal ethics).

### Network Security
Network security concepts, overlaps a fair bit with Network Defense from cisco but covered at a faster pace since this is one lesson block instead of a whole dedicated course.

### System Security
Securing the actual systems/hosts rather then the network around them. Similar territory to parts of Endpoint Security from cisco, again just covered faster and lighter.

---

## Module 2 — Web Application Security

### Cryptography
Crypto again, this is probably the 3rd or 4th time seeing crypto covered across different courses at this point (Intro to Cybersecurity, Network Defense, now here). Each time it goes a little different direction or adds something — this one leaned more into how crypto specifically protects web applications and data in that context, rather then the general PKI/hashing stuff Network Defense covered.

### Web Application Security
This was the standout new material for me. Covers vulnerabilities specific to web apps — the kind of stuff cisco never really got into since cisco's focus is networking/infrastructure, not application layer specifically. Thinking about how an app itself can be broken into (bad input validation, weak session handling, that kind of thing) is a genuinely different angle then network-focused security.

### Mobile Security
Security considerations specific to mobile devices — different attack surface then a normal computer, different considerations for app permissions, device management, that kind of thing. Cisco's Endpoint Security course focused on windows/linux, this filled in the mobile side which wasnt covered anywhere else so far.

**Lesson Summary**

## Module 3 — Incident Response and Forensics

### Cloud Security
Cloud security again — like crypto, this is a recurring topic (Network Defense had a whole module on it, Networking Devices touched it lighter). This version was somewhere in between those two in terms of depth.

### Incident Response and Forensics
Ties back directly to Cyber Threat Management module 6 from cisco (kill chain, diamond model, evidence handling) but this version goes a bit further into the actual forensics side specifically — collecting and preserving evidence properly, not just responding to the incident itself.

### Ethical Hacking
This is where it started feeling different from cisco's approach. Cisco frames pentesting as part of network security testing (one topic within a bigger module). This course treats ethical hacking as its own standalone thing with its own methodology and considerations, which honestly gave me a clearer picture of it as an actual career path/discipline rather then just one testing technique among several.

**First Assessment** — graded checkpoint here, first real evaluation in the diploma.

---

## Module 4 — Risk Management and Compliance

### Cyber Threat Intelligence
Threat intel again, similar ground to what Cyber Threat Management covered in cisco, reinforced rather then totally new.

### Risk Management and Compliance
Same deal, overlaps with the risk management module from Cyber Threat Management, good reinforcement of a topic that honestly needed the repetition since risk assessment concepts took some time to fully click the first time around.

### Secure Software Development
This one was genuinely new ground. Everything up to this point across every course has basically been about defending or attacking systems that already exist. This is the first real coverage of building security into software from the start instead of adding it after the fact — sometimes called shift-left thinking. Connected some dots for me about why secure coding practices matter as their own topic separate from network/system defense.

**Lesson Summary**

---

## Overall

This diploma worked well specifically because of how it complements cisco rather then just repeating it. Where topics overlapped (network security, system security, cloud security, threat intel, risk management) it mostly reinforced stuff already learned, which wasnt wasted time since repetition helped some of the shakier concepts (risk assessment specifically) actually stick better.

Where it added genuinely new material — web application security, mobile security, ethical hacking as its own discipline, and secure software development — those are real gaps cisco doesnt cover in any real depth, so this diploma filled them in even if not to expert level.

If i had to pick the most valuable new addition it'd be web application security, just cause its such a different mindset from the network-focused stuff cisco spends most of its time on, and its clearly relevant given how much of what runs on top of networks today is web applications specifically.
