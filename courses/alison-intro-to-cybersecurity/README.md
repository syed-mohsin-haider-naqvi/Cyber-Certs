# Diploma in Cyber Security — Alison

## About This Course

This ones bigger then i originally planned for honestly, its a full diploma not just a short intro course, so the folder name from before (alison-intro-to-cybersecurity) doesnt really fit anymore, renaming it to match what it actually is. 4 modules total, each one covering multiple topics with their own lesson counts, plus an assessment partway through.

Took this alongside the cisco courses to get broader coverage — cisco is deep on networking/defense specifically, this one covers stuff cisco doesnt really touch much, like web app security, mobile security, ethical hacking as its own topic, and secure software development.

**Status:** Completed

---

## What It Covered

**Module 1 — Network and System Security**
Intro to cybersecurity (basics, cybersecurity in the digital age, overview of threats/attack vectors, legal and ethical considerations), then network security specifically, then system security, wrapped with a lesson summary.

**Module 2 — Web Application Security**
Cryptography, web application security itself, and mobile security. This is the module that covered stuff cisco really didnt — web app specific vulnerabilities and mobile device security as its own dedicated topic instead of just touching on it briefly.

**Module 3 — Incident Response and Forensics**
Cloud security, incident response and forensics, and ethical hacking. Ends with the first graded assessment for the diploma.

**Module 4 — Risk Management and Compliance**
Cyber threat intelligence, risk management and compliance, and secure software development.

---

## What Actually Stuck

Web application security in module 2 was honestly the most useful new material for me specifically, since cisco doesnt really get into web app vulnerabilities in much depth — thats more OWASP territory which this course actually touches on. Different mindset from network security, thinking about how an application itself can be exploited rather then the network its running on.

Ethical hacking as its own dedicated topic (module 3) was also different from how the cisco courses frame pentesting — cisco mentions it as part of network security testing, this treats it as more of a standalone discipline with its own considerations, tools, and methodology.

Secure software development in module 4 connected some dots for me — up until this point most of what id learned was about defending/attacking systems after theyre already built, this is the first real coverage of building security in from the start (shift-left type thinking) rather then bolting it on after.

---

## Why This One Filled Real Gaps

Out of everything ive done so far, this diploma covers the widest spread of topics in the least depth per topic — which sounds like a downside but actually worked well alongside cisco's much deeper but narrower focus. Cisco goes deep on networking/defense/endpoints. This one gave me at least a working vocabulary and basic understanding of web app security, mobile security, cloud security, and secure dev — areas cisco barely touches. Not expert level on any of these after one diploma, but not starting from zero either if i need to go deeper later.
