# Introduction to Cybersecurity — Cisco Networking Academy

## Overview

This was one of the first courses I completed when I started learning cybersecurity.

I took it before moving into hands-on labs (TryHackMe, Hack The Box, LetsDefend) because I didn’t want to just follow steps without understanding what was actually happening.

The course is beginner-level, but it helped me build a proper foundation instead of learning things randomly.

Status: Completed

---

## What the Course Covered

- Basic cybersecurity concepts and why security matters  
- The CIA Triad (Confidentiality, Integrity, Availability)  
- Common attacks such as phishing, malware, and DoS/DDoS  
- Intro to encryption (data at rest vs in transit)  
- Basic network security concepts and layered defense  
- Overview of cybersecurity roles and career paths  

---

## What I Took From It

Before this course, I had seen a lot of cybersecurity terms online, but they didn’t really connect.

This course helped me organize everything properly.

The main concept that stayed with me was the CIA Triad. At first it seemed simple, but later when I started doing SOC labs, I realized it actually helps explain why something is considered a security issue.

For example, availability made more sense when looking at denial-of-service type alerts, and confidentiality connected directly to data exposure scenarios.

Even though the course is basic, I still find myself using these ideas when analyzing alerts in labs.

---

## How It Helped Me

This course didn’t include hands-on labs, but it made later practical work easier.

When I moved to platforms like TryHackMe, Hack The Box, and LetsDefend, I wasn’t just following steps. I had a better understanding of what the attack was doing and why it mattered.
