## CIA Triad

| Term | Meaning | Broken By |
|---|---|---|
| Confidentiality | Only authorized people can access data | Data breaches, weak access control |
| Integrity | Data hasn't been altered improperly | Tampering, man-in-the-middle attacks |
| Availability | Systems/data accessible when needed | DDoS, ransomware, hardware failure |

---

## Malware Types

| Type | Key Trait |
|---|---|
| Virus | Attaches to a legitimate file, needs a host to spread |
| Worm | Spreads on its own across a network |
| Trojan | Disguised as legitimate software |
| Ransomware | Encrypts files, demands payment |

---

## Social Engineering Tactics

| Tactic | What It Is |
|---|---|
| Phishing | Fake message trying to get clicks/credentials |
| Pretexting | Attacker invents a false scenario to extract info |
| Baiting | Leaving something enticing (e.g. USB) to compromise a target |

---

## Cryptography Quick Terms

| Term | Meaning |
|---|---|
| Encryption | Converts plaintext → ciphertext, reversible with the right key |
| Symmetric encryption | Same key encrypts and decrypts |
| Asymmetric encryption | Public key encrypts, private key decrypts |
| Hashing | One-way, not reversible — used for integrity checks, not secrecy |

---

## Defense-in-Depth Layers

- Firewalls — control traffic in/out
- Endpoint protection — catches malware on devices
- Access controls — restrict who reaches what
- Monitoring/logging — detection and investigation trail
