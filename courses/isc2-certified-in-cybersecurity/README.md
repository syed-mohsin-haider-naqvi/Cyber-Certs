# ISC2 Certified in Cybersecurity (CC) — Domain Study

## About This

ISC2 offers free study material for their entry-level Certified in Cybersecurity (CC) certification, split into 5 domains. Each domain has its own short course with a completion certificate issued at the end of it — separate from the actual CC certification itself, which requires sitting a proctored exam I haven't taken yet (~$50 candidate fee I'm holding off on until it makes more sense financially, covered in my main repo notes on this).

So to be clear on what this actually is: I have completion certificates for all 5 individual domain courses, not the full CC certification. Wanted to keep that distinction accurate rather than blur it — the domain certs show I went through the material, the actual CC cert requires the exam.

**Status:** All 5 domain courses completed, certificate issued for each. CC exam itself not yet taken.

## The 5 Domains

ISC2's official domain structure for the CC exam:

- **Domain 1 — Security Principles**
- **Domain 2 — Business Continuity (BC), Disaster Recovery (DR) & Incident Response Concepts**
- **Domain 3 — Access Controls Concepts**
- **Domain 4 — Network Security**
- **Domain 5 — Security Operations**

---

## What Each Domain Covered

**Domain 1 — Security Principles**
The fundamental rules of security — keeping data private, accurate, and available (basically CIA triad again, this framework really does show up everywhere). Covers best practices like the NIST framework, used to identify risks and make sure security efforts actually support what the business is trying to do, not just security for its own sake.

**Domain 2 — Business Continuity, Disaster Recovery & Incident Response**
Preparing for potential disruptions before they happen. Creating and testing crisis playbooks that define what to actually do when something goes wrong. Main goal is enabling a fast return to normal operations after a system failure so the business can keep running.

**Domain 3 — Access Controls Concepts**
Managing who can access what. Covers implementing strict systems, including multi-factor authentication, so people only have access to what they actually need — not more. The aim is solid data security through controlled access rather than open access with security bolted on after.

**Domain 4 — Network Security**
Creating a secure pathway for data moving across a network. Firewalls and other tools used to detect threats. Strong defense needed for data in transit specifically, whether that's office wifi or data moving to/from the cloud.

**Domain 5 — Security Operations**
The continuous, ongoing effort to actually maintain security day to day. Constant monitoring of systems, log reviews to catch vulnerabilities before they become real problems. When something does go wrong, a response gets initiated to resolve the issue, with security software helping enable a quick reaction.

## Why I Did This Alongside The Cisco Courses

A lot of this domain content overlaps with what cisco covers (network security, access control, incident response all show up in Network Defense and Cyber Threat Management specifically), but ISC2's framing is different — more industry-standard vocabulary, the kind of terminology that shows up directly in job postings and other certifications like Security+. Good to have both the cisco depth and the ISC2 standard terminology, since employers and job listings tend to reference ISC2/CompTIA style domain language pretty often.
