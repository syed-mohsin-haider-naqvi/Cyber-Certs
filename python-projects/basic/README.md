# Basics

Small scripts written while going through the Python Crash Course (see `courses/python-crash-course/`). These are practice, not real tools — just me applying stuff from the course modules to something slightly more interesting then the exact copy-paste exercises.

---

## Scripts

**grade_checker.py** — functions + if/elif/else practice (module 2). Takes a score, returns a letter grade. Also has my actual quiz scores from the crash course itself run through it, mostly cause i thought that was a funny way to test it with real data instead of made up numbers.

**password_strength.py** — for loops + string methods practice (module 3/4). Checks a password for length, uppercase, lowercase, numbers, special characters, and rates it weak/medium/strong. Wanted to practice on something security-related instead of a random example.

**port_lookup.py** — list comprehensions + dictionaries practice (module 4). Simple lookup dictionary for common ports, plus practicing list comprehensions to filter for insecure vs secure ports. Not real scanning, just python basics using networking terms I already know from the cisco courses.
