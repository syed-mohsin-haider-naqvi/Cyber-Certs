# Security Scripts

Python scripts related to SOC/security work. Built alongside SOC lab practice (HTB, TryHackMe, LetsDefend) as I figure out what's actually worth automating instead of doing manually every time.

---

## Planned / In Progress

- **log-parser/** — script to parse through a sample log file and flag specific patterns (failed logins, unusual access times, etc) instead of scanning manually
- **ip-osint-lookup/** — takes an IP and pulls basic OSINT info on it (geolocation, known reputation, that kind of thing) using public APIs
- **phishing-indicator-checker/** — checks a URL or email header against common phishing red flags rather then eyeballing it manually every time

Each one will get its own folder with a README explaining what it does, why I built it, what it uses, and what it actually looks like running — not just a link to raw code with no context.
